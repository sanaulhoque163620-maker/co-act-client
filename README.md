# CoAct - Community Action Platform

CoAct is a decentralized social deployment and community-service management application designed to initialize, trace, and coordinate mutual-aid networks and verified localized drive arrays.

## Live Site URL
[CoAct Live Platform](https://vercel.app)

## Project Core Features
- **Distributed Identity Grid:** Completely secure session management and profile trace synchronization powered by BetterAuth with custom MongoDB adapters.
- **Autonomous Campaign Node Deployment:** Full validation architecture for creating community drives, restricting past timeline scheduling dynamically.
- **Dynamic Structural Grid Synchronization:** Publicly accessible dashboard tracing six real-time upcoming events leveraging native MongoDB slicing mechanisms.
- **Global Matrix Mutation Control Desk:** Secure private control layers allowing campaign nodes to be mutated or purged exclusively by verified initiators.
- **Adaptive Theme Interface Toggle:** Native client-side state machine ensuring persistent synchronized dark and light mode UI ecosystem mapping.
